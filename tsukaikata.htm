CUI の書き方

画面の順番と、そこに出す文字は Excel（CUI）に書きます。cui.xlsx が基本です。CSV でも読めます。 プログラムは上から順に読み、1列目の名前の UI を表示します。

CUI の表。A列が UI、B列がタイトル、その下が変数です。

  • UI の表示列（A列） … 呼び出す画面の名前です。check と書けば ui/check.py が出ます。同じ名前が再登場したら、新しい起動です。
  • タイトル（B列） … UI 名の右隣です。画面の先頭に出ます。空なら出しません。
  • 変数の置き場 … UI 名の次の行からです。その行の A 列は空けます。B 列以降に、表示する文字や目標値などを書きます。
  • ＃について … A 列が #・＃・♯ で始まる行はコメント／見出しで、画面には渡りません。UI 名の直後の ♯ 行は、変数の見出しです。

空行や右端の空マスは読み飛ばします。見やすく隙間を空けて書いて大丈夫です。

UI の説明へ

メニュー

窓の右上の「メニュー」から開けます。見た目の色は、メニューから開く窓には使いません。

右上のメニュー。

  • 通信 … 使う COM ポートや速度、文字コードを決めます。接続ランプに出るポートもここです。データを垂れ流すタイプのCOM通信にのみ対応です。
  • 通信データの加工 … 受信した文字の切り方（そのまま／一部／カンマ区切り）と、文字か数値かを番号ごとに決めます。
  • 表示のカスタマイズ … 色・フォント・次へボタンの大きさなどデザインを改修できます。文字がはみ出る際は調整してください。メニューバー：上の細いところ。表示域：真ん中の広い部分。フッター：次へボタンのあるところ。
  • 設定 … 読み込む CUI、ログの保存先、次へ音、戻るを使うか、メニューの次へでコメントを書くか、などです。
  • 次へ … 条件を満たしていなくても先に進めます。コメント設定がオンなら、コメントを残せます。一番下の「次へ」とは別でエスケープ用です。
  • 記録確認 … log を見れます。
  • 戻る … ひとつ前の画面に戻ります。設定で使えなくできます。
  • UI一覧 … CUIに登録したUIのリストです。
  • 終了 … アプリを閉じます。このときまでの記録を log に書きます。
