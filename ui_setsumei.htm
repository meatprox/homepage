CUI の基本構成

Excel（CUI）は、どの UI を出すか、画面の先頭に何を出すか、その UI に何を渡すかを書く表です。マスの役割は次のとおりです。

ABC
UI名 タイトル
内容 内容
内容 内容

UI名 タイトル 内容

UI名 … 1行目の A 列です。check と書けば ui/check.py が出ます。同じ名前が再登場したら、新しい起動です。

タイトル … 1行目の B 列（UI名の右隣）です。画面の先頭に出ます。空なら出しません。

内容 … UI名の次の行からです。その行の A 列は空け、B 列以降に本文・項目・目標値などを書きます。列や行を足すと内容が増える UI があります。

A 列が #・＃・♯ で始まる行はコメント／見出しで、画面には渡りません。空行や右端の空マスは読み飛ばします。

tounyuuhyou

基本機能 … 投入の繰り返しです。行は全体重量・風袋・投入値・累計。目標があるときは下に残り（目標−累計）を出します。通信の１番のデータを使います。

次へ … 目標があるときは累計が目標の範囲内になった時。目標が無いときは1行でも揃った時点。

CUI … 1つ目が目標、2つ目が許容幅。CUI の行では表は増えません。画面で登録すると増えます。
